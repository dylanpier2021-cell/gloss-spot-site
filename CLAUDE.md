# The Gloss Spot — site repo

Static marketing site for **The Gloss Spot Auto Detailing** (Dominic Pierson,
Champaign County IL), generated by the Pierson Digital agent scripts in this
repo and deployed on Vercel.

- **Live:** https://www.theglossspotil.com (apex 307s → `www`; canonicals,
  sitemap and JSON-LD all use the `www` host — keep them matched)
- **Deploy:** Vercel serves `output/` directly. `vercel.json` sets
  `outputDirectory: output`, `cleanUrls: true`, plus the redirect and security
  header rules. There is no build step.

## Layout

| Path | What it is |
|---|---|
| `output/` | **The deployed site.** 63 pages + `blog/`. Edit here for one-off fixes. |
| `generate-landing-page.js` | Generator for every page type. ~126KB, holds the full CSS in a template literal. |
| `blog-generator.js` | Writes `output/blog/*` and `output/blog/posts.json`. |
| `sitemap-generator.js` | Rebuilds `output/sitemap.xml`. |
| `client-config.js` | All business data — phone, reviews, photos, colors, `domain`. |
| `api/` | Vercel serverless functions (GHL booking, free slots, feedback). |
| `Clients/Aricka Dean/` | **Unrelated** — KEI Events landing pages, inherited from the agent template. Not part of this site. |
| `lead_*.py` | Yelp lead scraper. Unrelated to the website; excluded via `.vercelignore`. |

## Editing gotchas

- **Fix the generator AND `output/`.** The CSS lives inline in every one of the
  68 built pages *and* in `generate-landing-page.js`. A CSS change applied only
  to `output/` is silently reverted the next time anyone regenerates. Patch both
  (a scripted find/replace across `output/*.html output/blog/*.html` plus the
  generator is the usual move).
- **Regenerating costs money and rewrites copy** — it calls the Anthropic API.
  Prefer targeted edits over `npm run generate` unless you actually want new text.
- Pricing lives in a `window.PRICING` object duplicated in
  `output/cost-calculator.html` and `output/book-an-appointment-1696.html`.
  They must stay identical; `packages.html` displays the same numbers as static
  markup. Change all three together.

## Environment

`.env` (local, for the generator) and the **Vercel** env are different sets —
see `.env.example`. The one that breaks production if missing is
`GHL_PIT_TOKEN`, read by everything in `api/`.

## Known open items

- `/` and `/Champaign-il` share an identical `<title>` and `<h1>`
  ("Car Detailing in Champaign, IL") — keyword cannibalisation, not yet resolved.
- `/Champaign-il` is the only capitalised URL on the site.
- No analytics installed: `googleAnalyticsId` / `facebookPixelId` in
  `client-config.js` are empty.
- Blog has not been published to since April 2026 despite
  `blogPostsPerDay: 3` and a `daily-cron.js`.
